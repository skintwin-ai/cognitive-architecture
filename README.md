## Getting Started

### Prerequisites

- Node.js 22.x or higher
- Python 3.11 or higher
- Modern web browser with JavaScript enabled

### Running the Visualization

#### Option 1: Standalone HTML

```bash
# Open the standalone HTML file in your browser
open heptavertonic_visualization.html
```

#### Option 2: React Component

```bash
# Install dependencies
npm install animejs

# Import and use the component
import HeptavertonicVisualization from './HeptavertonicVisualization';
```

### Working with the Financial Model

The financial model is provided as an Excel file (`skin_care_financial_model.xlsx`) and can be regenerated using the Python scripts:

```bash
# Install dependencies
pip install pandas openpyxl

# Run the scripts in order
python create_assumptions_sheet.py
python create_operational_costs_sheet.py
python create_cogs_sheet.py
python create_sga_sheet.py
python create_revenue_sheet.py
python create_group_model.py
```
